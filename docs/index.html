Claude meets your record collection.

An open-source Model Context Protocol server that lets Claude search the Discogs music database and read the authenticated user's collection, wantlist, and marketplace data — all read-only, all per-user OAuth.

01What it is

A remote MCP server you deploy to your own Cloudflare account. Claude connects to it over streamable HTTP and gains sixteen tools for browsing Discogs — both the public catalog and your private collection.

Two OAuth dances run end-to-end. Claude does OAuth 2.0 with the Worker (Dynamic Client Registration plus the Claude-issued metadata flow), and the Worker does OAuth 1.0a with Discogs on each connected user's behalf. Tokens live in Cloudflare KV, scoped to the OAuth grant; deleting the connector in Claude drops the entry. No tokens are shared between users, and no conversation content is stored server-side.

02Architecture

Two providers, one Worker. Claude talks OAuth 2.0 to the Worker; the Worker talks OAuth 1.0a to Discogs. The signer is implemented from scratch on Web Crypto and cross-checked against a reference implementation in the test suite.

Per-user isolation

Every connected user completes the Discogs flow individually. Their access token is bound to their OAuth grant; one user can never see another's data.

Read-only by design

No write tools ship in this release. The server cannot modify your collection, wantlist, or marketplace listings — every tool is annotated readOnlyHint: true.

From-scratch signer

OAuth 1.0a HMAC-SHA1 on Web Crypto, with RFC 3986 percent-encoding. A vitest suite cross-checks it against the oauth-1.0a reference implementation across six cases including unicode edges.

Hardened bootstrap

Sanitized OAuth error responses, Zod validation on KV stash and identity payloads, escaped origin in the landing page, KV stash deleted before token exchange, fifteen-second fetch timeouts.

03Tool catalog

Sixteen tools across four groups. All read-only.

Core lookup

search
Search the Discogs database by query or filters (type, artist, title, year, catno, barcode, format).
get_release
Full metadata for a specific pressing.
get_master
The canonical master release across all pressings.
get_master_versions
Every pressing of a master, with format and country.
get_artist
Artist profile, aliases, and members.
get_artist_releases
Releases credited to an artist, paginated.
get_label
Label profile, parent label, and sublabels.
get_label_releases
Releases published by a label.

Personal data (authenticated user)

get_identity
Your Discogs username and id.
get_collection_folders
List your collection folders.
get_collection
Releases in a folder (folder 0 returns everything).
get_wantlist
Your wantlist.

Marketplace

get_marketplace_listing
Fetch a marketplace listing by id.
get_price_suggestions
Discogs price suggestions by condition (requires seller account).
get_release_stats
Number for sale and lowest asking price.

Health

ping
Confirm the connection and report the authenticated username.

04What it feels like

Three sample interactions. The tool calls are the actual ones the model runs; responses are paraphrased for length.

You

Find the original UK pressing of OK Computer and tell me what's on side D.

Claude

I'll search for it, then pull the full pressing.

search {q: "OK Computer", artist: "Radiohead", country: "UK", format: "Vinyl"}
get_release {release_id: 1851062}

That's the 1997 Parlophone double-LP, catalog NODATA 02. Side D is "Lucky", "The Tourist", and the locked-groove run-out. The matrix etching reads "NODATA02 D1 ▲ TOWNHOUSE".

You

What's the average release year of records in my collection's All folder, and which decade is over-represented?

Claude
get_collection_folders {}
get_collection {folder_id: 0, per_page: 100}

Across 312 releases the mean year is 1994, median 1997. The 1990s account for 41% of the collection — heavily over-represented vs. a flat distribution. Your earliest is a 1962 Blue Note pressing; the most recent is from 2024.

You

I have a near-mint copy of Kid A on vinyl. Worth listing this week?

Claude
get_release_stats {release_id: 386058}
get_price_suggestions {release_id: 386058}

There are 47 copies for sale and the lowest asking price is $58. The Discogs suggestion for Near Mint is $74.12 (median over recent sold listings). With supply that thick, expect to clear closer to the floor than the suggestion — listing at $65 would put you in the top quartile of bids without undercutting.

05Deploy your own

There is no public hosted instance — clone and deploy your own Worker. Free Cloudflare account, free Discogs developer app, Node 20+. The README has the exact callback-URL dance; the abbreviated version:

  1. Clone and install. 
    git clone https://github.com/mcal8055/discogs_mcp.git
cd discogs_mcp
npm install
  2. Register a Discogs application at discogs.com/settings/developers. Save the Consumer Key and Consumer Secret. Set the Callback URL to https://<your-worker>.workers.dev/callback/discogs.
  3. Create a KV namespace for OAuth state and paste the returned id into wrangler.jsonc. 
    npx wrangler kv namespace create OAUTH_KV
  4. Set your Discogs secrets (encrypted at rest by Cloudflare): 
    npx wrangler secret put DISCOGS_CONSUMER_KEY
npx wrangler secret put DISCOGS_CONSUMER_SECRET
  5. Deploy. Wrangler prints your live URL. 
    npx wrangler deploy
  6. Connect in Claude. Settings → Connectors → Add custom connector → paste <your-worker-url>/mcp. Claude walks you through the Discogs login.

06Privacy posture

Self-hosted by design. When you deploy, you are the operator responsible for your users' data — treat the privacy policy as a template to adapt.

  • Per-user OAuth. Each connector completes the Discogs flow individually; tokens are scoped to the OAuth grant.
  • Tokens at rest. Stored in Cloudflare KV, readable only by the Worker runtime. Deleting the connector revokes the grant.
  • No conversation storage. The server doesn't read, persist, or transmit Claude conversation content beyond the explicit tool inputs.
  • Read-only upstream. No write tools. The server cannot modify any of your Discogs data.
  • Rate limits surfaced. Discogs caps authenticated requests at 60/min per token; HTTP 429s return a clear message rather than failing silently.
